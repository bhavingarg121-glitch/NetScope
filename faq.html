Frequently Asked Questions

Answers to common questions regarding cellular metrics, India network coverage, and Android device compatibility.

What is NetScope India?

NetScope India is an open-source mobile network analytics and diagnostics platform for exploring mobile network performance on the web and measuring cellular hardware telemetry on Android devices. Learn more in our Network Academy.

What do RSRP, RSRQ and SINR mean?

RSRP describes reference signal received power, RSRQ describes reference signal received quality, and SINR describes signal-to-interference-plus-noise ratio. Learn the physics behind these in our RF Engineering Guide.

Can I use NetScope with Jio, Airtel, Vi and BSNL?

Yes. The platform is designed for Indian cellular networks. NetScope supports Reliance Jio 5G Standalone, Bharti Airtel 5G Non-Standalone, Vodafone Idea 4G LTE-A, and BSNL Bharat 4G.

Is the Android app free and open-source?

The current NetScope APK is provided as a free download. Always download the APK directly from the official Download Hub or GitHub Releases.

Does NetScope require root access?

No root access is required. NetScope uses standard Android TelephonyManager APIs available on Android 8.0 Oreo through Android 15.
