NetScope India Features

A deep look into the hardware-level cellular diagnostic features built into the NetScope Android application.

📶

1. Signal Strength (dBm & ASU)

Raw RF signal telemetry displayed in decibel-milliwatts (dBm) and Arbitrary Strength Unit (ASU). Move beyond ambiguous 4-bar status icons to pinpoint signal dead zones in your room or office.

• Excellent: > -80 dBm
• Good: -80 to -90 dBm
• Fair: -90 to -105 dBm
• Poor: < -110 dBm
⚡

2. Network Speed Testing

High-precision download and upload bandwidth evaluation with live animated gauges. Direct socket streams measure real throughput under varying network congestion.

• Peak 5G & 4G speeds
• Average throughput curve
• Minimum data consumption mode
🌐

3. Latency, Ping & Jitter

Essential for online gaming (BGMI, Free Fire) and video conferences. Measures exact round-trip ping time in milliseconds and packet delay variation (jitter).

• Ping (ms)
• Jitter (ms)
• Packet Loss Percentage (%)
📡

4. Network Type & Generation

Identifies whether you are connected to true 5G SA (Standalone), 5G NSA, 4G LTE-Advanced, Carrier Aggregation (CA), or fallback 3G/2G protocols.

• 5G NR Standalone / Non-Standalone
• LTE-A with Multi-Carrier Aggregation
• VoLTE / VoNR voice status
📍

5. Cell Tower Telemetry

Technical cell parameters including Mobile Country Code (MCC 404/405 for India), Mobile Network Code (MNC), Cell ID (CID / eNodeB / gNodeB), and Tracking Area Code (TAC).

• MCC & MNC
• Cell Identity (CI)
• Physical Cell ID (PCI)
📊

6. Telemetry Analytics

Automated health scoring assessing overall connection quality, signal stability, and connection uptime during active mobile sessions.

• Overall Stability Index
• Signal Fluctuations Tracker
• Handover Monitoring
🗺️

7. Indoor & Outdoor Coverage

Test and evaluate signal penetration across different rooms in your house, underground basements, or high-rise apartments to find the sweet spot for data calls.

📱

8. Dual SIM & Hardware State

Seamless toggle between SIM 1 and SIM 2. View carrier profiles (e.g. Jio in SIM 1, Airtel in SIM 2), active data SIM designation, and modem hardware details.

📈

9. Local Measurement History

All diagnostic runs and speed tests are stored securely in local SQLite database on your device. Compare performance over days and weeks.

🔍

10. Network Socket Diagnostics

Run diagnostic probes verifying DNS server resolution latency, TCP handshake time, and HTTP gateway availability.
