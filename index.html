FAQ

Questions about NetScope

What is NetScope India?

NetScope India is a web and Android platform for exploring mobile network performance and measuring network information from an Android device.

What do RSRP, RSRQ and SINR mean?

RSRP describes reference signal received power, RSRQ describes reference signal received quality, and SINR describes signal-to-interference-plus-noise ratio.

Can I use NetScope with Jio, Airtel, Vi and BSNL?

The platform is designed for Indian cellular networks. Actual metrics available depend on the Android device, modem and carrier APIs exposed by the operating system.

Is the Android app free?

The current NetScope APK is provided as a free download. Always download the APK from the project's official GitHub release page.

How are map metrics gathered?

The mapping system combines regional base station telemetry, operator deployment parameters, and on-device measurement contributions from the NetScope Android application.
