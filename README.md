## 🌟 Key Features

- **📶 Signal Strength Analysis:** Real-time cellular signal quality in precise dBm and ASU levels.
- **⚡ Network Speed Testing:** Measure real download and upload transfer bandwidth on 5G, 4G LTE, and Wi-Fi.
- **🌐 Latency & Ping:** Round-trip latency, jitter, and packet loss evaluation.
- **📡 Network Generation:** Identifies 5G Standalone (SA), 5G Non-Standalone (NSA), 4G LTE-A, and VoLTE.
- **📍 Cell Telemetry:** Inspect MCC, MNC, TAC, eNodeB/gNodeB Cell IDs, and frequency bands.
- **🛡️ Privacy-First:** Zero personal data collection, no ads, no trackers. Telemetry is processed locally.
- **🇮🇳 Multi-Carrier Support:** Optimized for Indian telecom networks including Jio, Airtel, Vodafone Idea (Vi), and BSNL.
